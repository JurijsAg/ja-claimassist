# Späteres Hilfsskript: GitHub Issues aus Ticketplan erstellen

Dieses Paket enthält zunächst nur die Planung. Später kann ein Skript ergänzt werden, das aus `MVP_Ticketplan_JA_ClaimsAssist_v0.2.xlsx` automatisch GitHub Issues erzeugt.
