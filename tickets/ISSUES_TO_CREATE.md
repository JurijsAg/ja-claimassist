# MVP Issues – Vorschlag für GitHub

Diese Liste kann man als erste GitHub Issues übernehmen. Details stehen im Excel-Ticketplan.

## Epic 1 – Projektbasis & Prototyp
- Repository-Struktur anlegen
- HTML-Prototyp bereitstellen
- GitHub Pages Deployment aktivieren

## Epic 2 – Auth & Benutzerverwaltung
- Login-Maske umsetzen
- Nutzerrollen definieren
- Firmenzuordnung je Nutzer umsetzen
- Passwort-Reset vorbereiten

## Epic 3 – SNR-Vorgänge
- SNR-Schaden anlegen
- SNR-Nummer automatisch vergeben
- Schadenakte mit Tabs anzeigen
- Such- und Filterfunktion vorbereiten

## Epic 4 – KFS/KFZ-Modul
- KFS-Schaden nur für Schenk anlegen
- PF-ST Kennzeichenvalidierung vorbereiten
- KFZ-spezifische Dokumenttypen anzeigen

## Epic 5 – Subunternehmer-Haftbarhaltung
- Subunternehmerdaten erfassen
- Haftbarhaltungsvorlage befüllen
- Frist und Historie speichern

## Epic 6 – Unterlagen & KI-Prüfung
- Dokumentupload vorbereiten
- Dokumentstatus vorhanden/fehlt/zu prüfen anzeigen
- KI-Prüfregeln als erste Logik modellieren

## Epic 7 – Betrag, Versicherung, Historie
- Schadenbetrag speichern
- KRAVAG-Schadennummer speichern
- Historie/Vermerke erfassen
